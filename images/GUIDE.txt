# How to integrate your own images:

1. Add your image files to this 'images' folder.
2. Open 'websites.html' or 'demo.html'.
3. Locate the 'websiteData' object in the <script> section.
4. Add the file path (e.g., 'images/your-image.png') to the 'gallery' array of the corresponding website.
5. Save the file and refresh your browser.

The premium gallery system will automatically:
- Update the photo count badge.
- Generate thumbnails for your new images.
- Include them in the 'View' modal carousel.

Enjoy your seamless integration!
